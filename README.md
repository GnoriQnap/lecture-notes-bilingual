# Lecture Notes Bilingual

将课堂录音转写与对应课件整理成忠实、完整、按知识逻辑组织的中英或中韩双语 Obsidian 笔记。

## 内容

- `skills/lecture-notes-bilingual/SKILL.md`：完整的课堂笔记整理规则。
- `plugin.json`：插件元数据和 ChatGPT 插件界面信息。
- `.codex-plugin/plugin.json`：插件界面配置。

## 使用

在支持插件的 ChatGPT 环境中安装插件后，上传课堂录音转写文档和对应课件，并调用 **Lecture Notes Bilingual**。技能会先梳理知识地图，再按知识逻辑整理完整双语笔记。

## 隐私

本仓库公开后，任何人都可以查看、复制和分发仓库里的文件。课堂转写和课件不会随插件源文件发布。
